# PERSONAL WEBSITE REBUILD

## OVERVIEW
This is the project to rebuild my personal website, at the moment a long exposure photography website. The actual URL is: [https://www.alessandrotorri.it](https://www.alessandrotorri.it).
Github repository is here: [https://github.com/AlexDevsTheWeb/alessandrotorri.it](https://github.com/AlexDevsTheWeb/alessandrotorri.it).

The main goal for this phase is to re-create the exact look&feel in this project, adding the section "administrator" where I will manage the photos to show.

### PROCEDURE
Before starting anything we need to:
- use the docs/ folder as starting point of a wiki or documentation, that must be compliant with the llm-wiki by karpathy and the OKF by Google. I've already created the raw/ folder, we need to move on from here.
- the documents already present in the docs/ folder must be inspected and we need to decide if they are ok or if we can trash them.
- every single new feature, or every new single bug etc must have a new page in the wiki or an update in the relevant pages in the wiki.
- There is a file "blueprint.md" in the root and we need to understand what we should do with it.
- this project will be coded with agentic help, so we need to be able to user claude code, opencode, pi and all the others agentic systems, so we need to be sure every agent can read and follow the same rules.
- after we created the wiki, and the skills for the agents, we should update the libraries.
- in the end we can start create the website clone.
- we have access to all github cli tools, so we can use github issues, github actions etc...
