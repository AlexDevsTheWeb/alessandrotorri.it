# Task Specification for OpenCode: Release v1.0.0 & CI/CD Automation

## 1. Context & Objective

The feature branch PR #26 has been merged into `development`. The master image catalog, dynamic gallery management, and GitHub discovery are fully implemented and verified. Your mission is to prepare, verify, and execute the official **Release v1.0.0** of `alessandrotorri.it`, automate GitHub Actions CI/CD workflows, update repository wiki docs, and close completed GitHub issues.

---

## 2. Execution Tasks

### Task 1: GitHub Actions Workflows Audit & Hardening

1. Inspect or create `.github/workflows/deploy.yml`:
    - Ensure it triggers on `push` to `main` and on tags (`v*`).
    - Steps: `actions/checkout@v4`, `actions/setup-node@v4` (Node 22), `npm ci`, `npm run lint`, `tsc -b`, `npm run build`.
    - Deploy step: Use `FirebaseExtended/action-hosting-deploy@v0` targeting channel `live`.
    - Ensure `firestore.rules` deployment step is included or documented.

2. Inspect or create `.github/workflows/preview.yml`:
    - Ensure it triggers on `pull_request` against `development` or `main`.
    - Runs linting, typechecking, build, and deploys a temporary preview URL.

### Task 2: Release Branch & Tag Strategy

1. Check if `main` branch exists in the remote repository.
    - If `main` does not exist, create `main` from `development`.
    - If `main` exists, prepare a Pull Request or merge commit from `development` to `main`.
2. Ensure `package.json` version is updated to `1.0.0`.
3. Create a clean git tag `v1.0.0` with release notes summarizing the rebuild milestones.

### Task 3: Wiki Documentation & GitHub Issues Update

1. Update `docs/wiki/rebuild-plan.md` marking Phase 6 (Admin) and Phase 7 (Release v1.0) as COMPLETE.
2. Update `docs/wiki/overview.md` setting current system status to `v1.0.0 Stable Production`.
3. Generate a release summary document `docs/raw/2026-11-18-release-v1.0.md` detailing all delivered capabilities.
4. Prepare closure notes for GitHub Issues:
    - Issue #1: Closed (Merged via PR #23 / PR #19 dependency refresh).
    - Issue #2: Closed (Public site phases 0-5 and dynamic catalog complete).
    - Issue #3: Closed (Admin route protection & firestore rules verified).
    - Issue #14: Closed (Documented in decision 0016/0018).

---

## 3. Verification Criteria

- Run `npm run lint` -> Must pass clean.
- Run `tsc -b` -> Must pass with 0 errors.
- Run `npm run build` -> Production bundle generated without warnings.
- Output a detailed `IMPLEMENTATION_PLAN.md` before executing file modifications.
