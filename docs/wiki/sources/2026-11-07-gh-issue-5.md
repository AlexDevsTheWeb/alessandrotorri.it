# Summary

Issue #5 asks to clear the 4 high-severity advisories in `@grpc/grpc-js@1.9.16`, pulled in by `firebase@12.19.0 -> @firebase/firestore@4.17.2`. The issue lists three options: evaluate Firebase 13, add a scoped `overrides` entry for `@grpc/grpc-js@^1.14`, or document the accepted risk. Acceptance: `npm audit` is clean, or the remaining risk is documented with a decision record.

# Analysis

- Firebase 13.2.0 still resolves a vulnerable `@grpc/grpc-js`: not a fix on its own.
- The scoped override to `^1.14.7` clears `npm audit --omit=dev` without touching Firebase.
- The `firebase-data` chunk is byte-identical before and after, so the browser bundle is unchanged.
