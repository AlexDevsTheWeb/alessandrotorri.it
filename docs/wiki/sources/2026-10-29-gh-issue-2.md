# Summary

Issue #2 covers phases 3–5 of the public rebuild. This loop implements **phases 3 and 4**: the 9-cover gallery grid on `/` and `/gallery`, and the single-collection feed with captions and a keyboard lightbox on `/gallery/:slug`.

# Phase 3 outcome

- New `src/components/CollectionGrid.component.tsx` — responsive `Grid` (`xs: 12`, `sm: 6`) over `COLLECTIONS`.
- New `src/components/CollectionCover.component.tsx` — 16:9 `ProgressiveImage`, centered uppercase title inside the cover, gradient overlay, no entrance animation (later refined by [decision 0008](/decisions/0008-visual-refinements.md)).
- `GalleryPage` now renders `CollectionGrid`; the "Explore the Collections" heading and demo `PhotoGallery` usage are gone.
- `HomePage` renders the same `CollectionGrid` directly, matching the live site where `/` is the gallery ([decision 0007](/decisions/0007-home-gallery-grid.md)). The Unsplash hero, commented Firestore blocks, and `height: 3000px` hack are removed.
- Deleted the dead `src/components/Navbar.tsx`.

# Phase 4 outcome

- All 9 collection photo lists were captured from the live site: **89 photos** with real CDN URLs, Italian captions and aspect ratios, in `src/data/collections.photos.ts`. The favorite collection has its full 24.
- `CollectionPage` now reads the slug with `useParams`, looks up `COLLECTIONS` and `PHOTOS`, and no longer queries Firestore.
- Breadcrumb `Gallerie / {title}`, centered uppercase H1, single-column feed at `maxWidth="md"`.
- Each photo is a keyboard-accessible button wrapping `ProgressiveImage`; caption below in `body2` secondary.
- New `PhotoLightbox` component: fullscreen dark `Dialog`, blurred backdrop, image at up to 75vh, caption + “Dati EXIF non disponibili”, prev/next, Esc/arrow keys, side arrows on desktop, arrows below on mobile.
- `ProgressiveImage` now accepts an optional placeholder, so feed images can load without a synthetic blur asset.

# Verification

- `npm run lint` — clean.
- `npm run build` — succeeds.
- `/gallery/01-favorite` resolves 24 photos with real captions.
- Bundle: 1.267 MB / 391.74 kB gzip (down from 1.357 MB; the unused demo gallery is tree-shaken).
- `PhotoLightbox` uses MUI `Dialog`, which locks body scroll while open.

# Remaining in issue #2

- Phase 5 — titles/OG, robots/sitemap, responsive audit, lazy routes, error boundary, bundle splitting.
