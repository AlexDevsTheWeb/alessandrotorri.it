# Summary

Issue #6 is the majors evaluation deferred from the in-range refresh. The first major adopted is **Material UI 9.5**: `@mui/material`, `@mui/icons-material`, and `@mui/lab` (v9 beta), with `@mui/system`, `@mui/utils`, and `@mui/styled-engine` resolved to 9.5.0. React 19.3.1 and Emotion 11.14 already satisfy the v9 peer ranges.

# Migration changes applied

- `Dialog` `PaperProps` → `slotProps.paper` (removed in v9).
- System props moved into `sx`:
  - `Box my={4}` → `Box sx={{ my: 4 }}`
  - `Stack alignItems="center"` → `sx={{ alignItems: 'center' }}`
  - `Grid justifyContent="center"` → `sx={{ justifyContent: 'center' }}`
- `nativeButton={false}` added to `Button` instances rendered through React Router `Link`, so v9 does not warn about a native `<button>` resolving to an `<a>`.
- No `GridLegacy`, `disableEscapeKeyDown`, `MuiTouchRipple`, or removed `*Outline` icon imports were present.
