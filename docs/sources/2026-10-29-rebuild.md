# Summary

The owner is rebuilding the current long-exposure photography site (<https://www.alessandrotorri.it>, repo `AlexDevsTheWeb/alessandrotorri.it`) as this project. The phase goal is to recreate the **exact look & feel** and add an **administrator section** for managing photos. Before coding, the project must establish a documentation layer that works for humans and every agentic tool, then refresh dependencies, then build the site clone.[^raw-rebuild]

# Key Points

- `docs/` must become a wiki compliant with Karpathy's llm-wiki pattern and Google's OKF; `docs/raw/` is the immutable source layer.
- Existing docs must be inspected and either kept, updated, or trashed — with a decision, not by default.
- Every new feature, bug, or change must create or update wiki pages in the same change.
- `blueprint.md` at the repository root must be dispositioned.
- Multiple agents (Claude Code, OpenCode, Pi, others) must read and follow the same rules.
- Libraries are updated only after the wiki and agent skills exist.
- The website clone starts only after that foundation.
- GitHub CLI is available: issues, PRs, Actions, and project tooling are in scope.
